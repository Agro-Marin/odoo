# The `Owner.method` points that addons outside `web` reach — by `extends`
# or by `patch()`, which depend on the same contract and are merged here:
# web's extension surface, as it is rather than as anyone designed it.
# Each entry names the consumer checkout(s) reaching it — its provenance —
# and the gate judges only the scopes present in the environment.
#
# Shrink-only, per scope. A point pinned for a scope that no longer
# overrides it fails until the entry is shrunk, so giving up surface is
# recorded; one overridden from a scope it is not pinned for fails as
# new exposure there.
#
# `js_public_surface.py` pins the MODULES other addons import. This pins
# the METHODS they override — a contract the first cannot express, and
# which no other gate in this directory models.
#
