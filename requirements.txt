# Runtime dependencies for the Odoo server and a default addon install.
#
# Versions are chosen from PyPI and validated on Python 3.14 (the floor is
# MIN_PY_VERSION in odoo/release.py). They are NOT tracked against the
# python3-* packages of Ubuntu 24.04 (Noble) or Debian 13 (Trixie), which is
# what this header used to claim: Noble froze in April 2024 and Trixie in
# mid-2025, while the pins below already require cryptography, Pillow, lxml,
# psycopg and pdfminer.six releases that postdate both. The rule described
# almost none of the lines it governed, so it is retired here rather than left
# standing as a brake on upgrades. `setup/requirements-check.py` still renders
# the distro comparison on demand for anyone packaging against one.
#
# What belongs where:
#   requirements.txt       the server and a default addon install
#   requirements-test.txt  needed to RUN the suites, not to run the server
#   requirements-dev.txt   linters, type checkers, native-extension build tools
#
# A library used by exactly one addon is declared in that addon's
# __manifest__.py `external_dependencies` and pinned in its own repo's
# requirements.txt (doc/coding_guidelines.rst §1.2) — not here.
