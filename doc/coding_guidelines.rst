===========================
AgroMarin Coding Guidelines
===========================

:Status: **DEPRECATED — moved to the knowledge repository**

The canonical AgroMarin coding guidelines live in the sibling ``knowledge``
repository:

    ``knowledge/agromarin-knowledge/reference/odoo/agromarin-guidelines.md``

That document is the single authoritative source for every coding rule in
``$ACTIVE_REPOS`` (module structure, Python, XML, JavaScript, CSS/SCSS, tests,
git, translations, code review checklist, security, performance, migration
scripts, and Appendices A–D). Rule changes go through its *Change protocol*.

This file held a full copy of the guidelines until v4.2 (2026-07-01) made the
knowledge-repo document canonical; the stale v4.1 body was removed in t24540.
Section numbers are unchanged, so an existing ``coding_guidelines §N``
citation in a code comment or workflow header resolves against the canonical's
``§N``.
